## Virtual Machine 

A virtual machine is software that acts like a completely separate computer running inside a physical computer. Each VM is given virtual hardware such as storage, RAM, CPU cores and networking. Even though multiple VMs share the same physical hardware, each os acts like it is running on its own computer.

## Hypervisor

A hypervisor is a software that allows one physical computer to run multiple indepndent virtual machines by managing and allocating the computer's hardware resources (CPU, storage memory etc.) to each VM.
